# Basic Overview of Cloud and AWS

## What is Cloud Computing?

Cloud computing is the delivery of computing services such as servers, storage, databases, networking, and software over the Internet. Instead of owning physical hardware, users can access these resources whenever needed.

---

## Cloud Computing Basics

### On-Demand Delivery
- Cloud resources are available whenever required.
- Resources can be provisioned and released quickly.
- Provides flexibility and scalability.

### Pay-as-You-Go Model
- Users pay only for the resources they consume.
- Eliminates large upfront infrastructure costs.
- Helps optimize operational expenses.

---

## Core Cloud Services

### Compute
Provides the processing power required to run applications and workloads.

### Storage
Stores files, documents, images, videos, backups, and other data securely in the cloud.

### Database
Provides services to store, manage, and retrieve structured and unstructured data efficiently.

### Networking
Enables communication between cloud resources and users through services such as virtual networks, load balancers, and DNS.

---

## Cloud Service Models

### Infrastructure as a Service (IaaS)
Provides the basic cloud infrastructure, including:
- Virtual Machines
- Storage
- Networking

The customer is responsible for managing the operating system and applications.

**Example:** Amazon EC2

---

### Platform as a Service (PaaS)
Provides a platform for developing, testing, and deploying applications without managing the underlying infrastructure.

Includes:
- Operating System
- Runtime Environment
- Middleware
- Development Tools

**Example:** AWS Elastic Beanstalk

---

### Software as a Service (SaaS)
Provides fully managed software applications over the Internet.

Users simply access the application through a web browser.

**Examples:**
- Microsoft 365
- Gmail
- Salesforce

---

## Cloud Deployment Models

### Public Cloud
Cloud infrastructure owned and managed by third-party cloud providers. Resources are shared among multiple customers.

### Private Cloud
Dedicated cloud infrastructure for a single organization, offering greater control, customization, and security.

### Hybrid Cloud
A combination of public and private clouds, allowing data and applications to move between both environments.

---

## Advantages of Cloud Computing

- Cost-effective (Pay only for what you use)
- Easy scalability
- Faster deployment
- High availability
- Global accessibility
- Reduced infrastructure management

---

## Historical Background

### John McCarthy
John McCarthy proposed that computing could someday be delivered as a public utility, similar to electricity.

### Salesforce
Salesforce was one of the first companies to successfully deliver software over the Internet, making the Software as a Service (SaaS) model popular.

---

## What is AWS?

Amazon Web Services (AWS) is Amazon's cloud computing platform that provides a wide range of cloud services for building, deploying, and managing applications.

Some commonly used AWS services include:
- Amazon EC2 – Virtual Servers
- Amazon S3 – Object Storage
- Amazon RDS – Managed Databases
- Amazon VPC – Virtual Networking
- AWS IAM – Identity and Access Management
- AWS Lambda – Serverless Computing

---

## Key Takeaways

- Cloud computing delivers IT resources over the Internet.
- Compute provides processing power.
- Storage stores data securely.
- Databases manage structured and unstructured data.
- Networking connects cloud resources.
- IaaS provides infrastructure.
- PaaS provides a development platform.
- SaaS provides ready-to-use software.
- Public, Private, and Hybrid are the three primary cloud deployment models.
- AWS is one of the leading cloud service providers.
